# MVQueen self-hosted fonts

The fonts preserve the storefront’s existing Cormorant Garamond and Jost families, weights, italic style, and Unicode coverage. Unmodified WOFF2 subsets were downloaded from the same Google Fonts CSS request used by the previous theme. Shopify asset URLs now serve them, and only the two regular Latin faces are preloaded. Font display remains `swap`.

License copies ship in the theme assets as `mvq-cormorant-garamond-OFL.txt` and `mvq-jost-OFL.txt`. Both families use the SIL Open Font License 1.1.
