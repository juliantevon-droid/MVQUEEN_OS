# Logo Usage Guide
## MVQUEEN_OS / 02_Brand_Identity

---

## Purpose

The MVQUEEN logo is the visual symbol of brand identity. This guide ensures consistent, professional logo deployment across all touchpoints.

---

## Logo Specifications

### Full Logo (Primary)
- **Dimensions:** 200px width (minimum digital), 1.5" width (minimum print)
- **Format:** PNG with transparency (recommended for digital), PDF for print
- **Color:** Full color on white or brand background
- **File Location:** 02_Brand_Identity/assets/logo_primary_full.png

### Mark Only (Secondary)
- **Dimensions:** 80px width (minimum digital)
- **Format:** PNG with transparency
- **Use:** Social media profiles, favicon, small space applications
- **File Location:** 02_Brand_Identity/assets/logo_mark_only.png

### Horizontal Logo
- **Dimensions:** 300px width (minimum digital)
- **Use:** Website header, wide applications
- **File Location:** 02_Brand_Identity/assets/logo_horizontal.png

### Vertical Logo
- **Dimensions:** 150px width (minimum digital)
- **Use:** Social media stories, narrow spaces
- **File Location:** 02_Brand_Identity/assets/logo_vertical.png

---

## Clear Space

**Minimum Clear Space:** 20px on all sides of the logo

Clear space is the invisible border that protects the logo from competing visual elements. Nothing should enter this space.

```
┌─────────────────────────────────────────────┐
│                                             │
│          [20px minimum clear space]        │
│                                             │
│              ┌──────────────┐              │

│              └──────────────┘              │

│                                             │
└─────────────────────────────────────────────┘
```

## Size Guidelines

### Minimum Sizes
| Application | Minimum Size | Format |
|---|---|---|
| Digital (web) | 80px width | PNG |
| Mobile app | 60px width | PNG |
| Print (magazine) | 1" width | PDF |
| Print (business card) | 0.5" width | PDF |
| Embroidery | 1" width | — |
| Social media profile | 200px square | PNG |
| Email signature | 150px width | PNG |

### Maximum Sizes
- No maximum; scale proportionally without distortion
- Maintain aspect ratio at all times

## Background Usage

### Acceptable Backgrounds
- Soft Cream (#FFF8F0)
- Pearl White (#FAFAF8)
- Ivory (#F5F1EB)
- Blush (#F5E6E0)
- Charcoal (#2C2C2C) — use reverse white logo
- Deep Rose (#8B4A5C) — use reverse white logo
- Natural textures (wood, linen, marble)
- Subtle photography (out of focus, muted)

### Forbidden Backgrounds
- Competing brand colors
- Busy, cluttered photography
- Clashing color combinations
- Patterns that compete with logo visibility
- Too-similar colors (no contrast)

## Positioning Rules

### Website
- **Header:** Top-left or center (preferred: top-left)
- **Size:** 150–200px width
- **Navigation:** Include link to homepage
- **Footer:** Smaller version (80–100px)

### Social Media
- **Profile Picture:** Mark-only version, 200x200px minimum
- **Header/Banner:** Full logo, 600x200px recommended
- **Story:** Full logo with 20px clear space
- **Post:** Include logo in bottom-right corner (15% of image width)

### Email
- **Header:** 150–200px width
- **Signature:** 100–120px width
- **Footer:** 80–100px width
- **Alt Text:** "MVQUEEN" for accessibility

### Packaging
- **Box:** 2–4" width (full color or foil)
- **Sleeve:** 1–2" width
- **Hang Tag:** 0.75–1" width
- **Tissue:** Optional small mark

### Print Materials
- **Business Card:** 0.5" width (bottom-right corner)
- **Letterhead:** 0.75–1" width (top-left or centered)
- **Brochure:** 1–1.5" width (cover or header)
- **Poster:** Minimum 2" width

---

## Distortion Rules

### Allowed
- Scale proportionally (maintain aspect ratio)
- Rotate only for specific design purposes (rotate 90°/180° max)
- Change colors (use approved color variations only)

### NOT Allowed
- Stretch horizontally or vertically
- Skew or shear the logo
- Add drop shadows, glows, or effects
- Outline or stroke the entire logo
- Change the order of logo elements
- Add or remove elements from logo
- Place text inside the logo
- Rotate to non-standard angles

## File Naming Convention

All logo files must follow this naming convention:

```
logo_[type]_[color]_[format].[extension]
```

**Types:**
- primary_full
- mark_only
- horizontal
- vertical

**Colors:**
- full_color
- grayscale
- reverse_white
- gold
- charcoal

**Formats:**
- web (for digital, sRGB)
- print (for print production, CMYK)

**Examples:**
- logo_primary_full_full_color_web.png
- logo_mark_only_white_print.pdf
- logo_horizontal_gold_print.pdf

## Responsive Logo Behavior

### Desktop (1024px+)
- Use full logo or horizontal variation
- Minimum 150px width
- Position in header or footer

### Tablet (768px–1024px)
- Use full logo or mark-only
- Minimum 100px width
- May stack or reposition for space

### Mobile (< 768px)
- Use mark-only version
- Minimum 60px width
- Must remain visible in header
