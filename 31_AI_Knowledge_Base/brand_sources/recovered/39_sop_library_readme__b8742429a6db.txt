# 📋 MVQUEEN — SOP Library

---

## Purpose

The SOP Library is the operational backbone of MVQUEEN — a master collection of Standard Operating Procedures governing every repeatable process in the business.

SOPs exist because:
- Consistency is a luxury standard
- Processes should not live in one person's head
- Scaling requires documented systems
- Quality cannot be maintained without defined standards

If it happens more than once in MVQUEEN — it has an SOP.

## Core SOPs (Detailed)

---

### SOP-001 — Product Upload

**Trigger:** New product ready for store
**Owner:** Founder / VA
**Time required:** 30-45 minutes per product

**Steps:**
```
□ 1. Gather all product details (name, description, specs, pricing)
□ 2. Load Product Copy Pipeline from 33_Content_Pipelines/
□ 3. Generate product copy using AI_Workflows + Product_Description_Prompts
□ 4. Review copy against Tone Guide
□ 5. Prepare all product images (minimum 4 per product)
□ 6. Resize images to Shopify specs (2048x2048px recommended)
□ 7. Write alt text for every image
□ 8. Log into Shopify → Products → Add Product
□ 9. Enter: Title, Description (formatted), Price, Compare at Price
□ 10. Upload images in correct order (hero first)
□ 11. Add alt text to each image in Shopify
□ 12. Set inventory quantity and tracking
□ 13. Add product to correct collections
□ 14. Apply all relevant tags
□ 15. Enter SEO meta title and meta description
□ 16. Set product URL (clean, keyword-rich)
□ 17. Set up upsell/cross-sell pairings
□ 18. Preview product page on mobile and desktop
□ 19. Publish or schedule publish date
□ 20. Add to content calendar for launch content
```

### SOP-002 — Customer Service Response

**Trigger:** Customer inquiry received
**Owner:** Founder / Customer Service Rep
**Response target:** Under 4 hours during business hours

**Response Framework:**
```
1. ACKNOWLEDGE — Validate her experience before solving anything
2. CLARIFY — Understand the full situation if needed
3. SOLVE — Provide the clearest possible resolution
4. ELEVATE — Leave her feeling better than before she reached out
5. DOCUMENT — Log issue type for pattern tracking
```

**Response Templates Location:** `09_Shopify_Systems/Customer_Support_SOP.md`

**Tone Rules:**
- Never defensive
- Never dismissive
- Never robotic or copy-pasted without personalization
- Always warm, human, and solution-focused
- Every response ends with an open door — not a closed door

**Escalation Triggers:**
- Order value over $150 with issue → Founder handles directly
- Customer threatening chargeback → Resolve immediately, offer replacement or refund
- Public social media complaint → Respond within 1 hour, move to DM

### SOP-003 — Email Campaign Launch

**Trigger:** Campaign date on content calendar
**Owner:** Founder / Marketing Manager
**Timeline:** Begin 5 days before send date

**Steps:**
```
□ Day 5: Define campaign goal, audience segment, offer
□ Day 4: Write email (subject lines x3, preview text, body, CTA)
□ Day 3: Review against Tone Guide + brand standards
□ Day 2: Design layout in email platform, add images
□ Day 1: Send internal test email, check on mobile
□ Send day: Schedule for optimal send time
□ +2 days: Review performance metrics
□ +7 days: Log results in analytics system
```

**Send checklist:**
```
□ Subject line finalized (best of 3 options)
□ Preview text set
□ From name correct (MVQUEEN — not platform default)
□ Images load correctly
□ All links tested and working
□ Unsubscribe link present
□ Mobile preview checked
□ Spam score checked (under 3)
□ Audience segment correct
□ Send time scheduled
```

### SOP-004 — Influencer Outreach

**Trigger:** Influencer identified for potential partnership
**Owner:** Founder / Marketing Manager

**Steps:**
```
□ 1. Vet influencer against brand alignment criteria (see below)
□ 2. Review their last 30 posts — aesthetic, tone, audience response
□ 3. Check engagement rate (target 3%+ for nano/micro)
□ 4. Check audience demographics — matches MVQUEEN target?
□ 5. Send initial DM or email (warm, personal, not template-obvious)
□ 6. If interested — send gifting or paid collaboration proposal
□ 7. Send influencer agreement for signature
□ 8. Ship product with brand insert card
□ 9. Brief on content requirements (but don't script them)
□ 10. Set posting deadline and follow up 48hrs before
□ 11. Review content before it posts (if paid collaboration)
□ 12. Track performance for 30 days post-posting
□ 13. Log result in influencer database
```

**Influencer Vetting Criteria:**
| Criteria | Requirement |
|----------|------------|
| Aesthetic alignment | Feminine, soft, elevated — not harsh or performative |
| Audience size | Nano (1k-10k) or Micro (10k-100k) preferred for authenticity |
| Engagement rate | 3%+ minimum |
| Audience demographics | 18-45 women, aligned with target personas |
| Content quality | Consistent, intentional, brand-adjacent |
| Values alignment | No content contradicting MVQUEEN values |

### SOP-005 — Weekly Analytics Review

**Trigger:** Every Monday morning
**Owner:** Founder / Marketing Manager
**Time required:** 30 minutes

**Review Sequence:**
```
□ 1. Open Shopify Analytics — weekly revenue vs. prior week
□ 2. Check conversion rate — up or down?
□ 3. Top 5 products by revenue this week
□ 4. Traffic sources — where did visitors come from?
□ 5. Email platform — last send open rate + CTR
□ 6. Social analytics — best performing post of the week
□ 7. Ad platform — ROAS and spend summary
□ 8. New subscribers vs. unsubscribes
□ 9. Any customer service patterns worth noting?
□ 10. Document key insights in 14_Data_And_Analytics/
□ 11. Set one optimization action for the coming week
```

## SOP Creation Standard

When writing a new SOP, every SOP must include:

| Element | Description |
|---------|-------------|
| Trigger | What initiates this SOP? |
| Owner | Who is responsible? |
| Time required | How long does this take? |
| Steps | Numbered checklist — every step actionable |
| Quality check | How do we know it was done correctly? |
| Escalation | What happens if something goes wrong? |

**SOP Naming:** `SOP-[NUMBER] — [NAME]`
**SOP Review:** All SOPs reviewed quarterly for accuracy and relevance.
