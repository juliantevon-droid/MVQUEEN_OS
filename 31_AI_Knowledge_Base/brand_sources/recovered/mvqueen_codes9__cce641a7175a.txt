MVQueen Omniluxe Engine — Systems & Brand Brain Documentation




Executive summary



The MVQueen Omniluxe Engine is a fully modular, deterministic, persona‑aware brand
engine designed to generate:
- Editorial copy (short, medium, long, persona‑aware, SEO‑aware)

- Alt text (short, medium, long, persona‑aware, SEO‑aware)

- SEO phrases, tags, and collections

- Shopify‑ready metafields

- Shopify‑ready CSV rows

- A complete, structured product “brain” for each item



The engine is built to be:



- Deterministic — same input → same output

- Modular — each subsystem is isolated and extendable

- Brand‑safe — vocab and frames live in brand_brain

- Shopify‑ready — metafields + CSV exporter

- Beginner‑friendly — clear modules, no magic

   3. How to use the engine



Run on a single product (CLI)



From the project root:



`bash
Python -m mvqueen_engine.main

`



Then paste a product description when prompted, e.g.:



           ➢ Black satin slip dress with lace trim



You’ll get a full JSON‑like output printed:



- detection (category, persona, trend, etc.)

- editorial (short/medium/long/persona/category/SEO)

- alt text (short/medium/long/persona/category/SEO)

- tags

- collections

- metafields

- SEO primary/secondary

`python

    4. How to extend the engine (safely)



Core rules



- Never replace. Never rewrite. Always append.

- Keep vocab in brand_banks.py.

- Keep logic in the correct module.

- Always use deterministic helpers from utils/deterministic.py.




Adding new detection logic



Where: brand_brain/detection.py



    1. Add a new keyword map:



`python

COLOR_KEYWORDS = {
    “black”: [“black”, “noir”],

    “white”: [“white”, “ivory”],

    “red”: [“red”, “crimson”],

}

`



     2. Add a new detector:



`python

Def detect_color(text: str) -> str:

    Text_lower = text.lower()

    For color, keywords in COLOR_KEYWORDS.items():

      If any(k in text_lower for k in keywords):

        Return color

    Seed = deterministic_seed(text)

    Return deterministicchoice(seed, list(COLORKEYWORDS.keys()), salt=”color”)

`



     3. Optionally wire into tags, metafields, collections.




Adding new editorial behavior



Where: brandbrain/brandlanguage.py



- Add a new function like generateeventeditorial(text: str)
- Use existing helpers: selectadj, selectverb, select_confidence, detection functions

- Keep it deterministic (always seed from text)




Adding new metafields



Where: metafields/metafield_engine.py



     1. Add a new function:



`python

Def color_metafield(text: str) -> dict:

    From ..brandbrain.detection import detectcolor

    Return {“color”: detect_color(text)}

`



     2. Add it into generateallmetafields:



`python

Metafields.update(color_metafield(text))

`




Adding new tags or collections



- Tags: brand_brain/tags.py
- Collections: brand_brain/collections.py



Follow the existing pattern:

Create a small generator → add it to the master aggregator.




   4. Brand Brain vocab expansion guide



Where vocab lives



File: brandbrain/brandbanks.py



You already have:



- ADJECTIVES

- SENSORY_VERBS

- CONFIDENCE_PHRASES

- EDITORIAL_FRAMES




How to safely add more vocab



   1. Add more adjectives



`python

ADJECTIVES = [
    # existing ones…

    “luminous”,

    “sculpted”,

    “weightless”,

    “molten”,

    “glassy”,

]

`



- Don’t rename the variable.

- Just append more strings.

- Keep them short, brand‑aligned, and reusable.




     2. Add more sensory verbs



`python

SENSORY_VERBS = [

    # existing ones…

    “catches the light”,

    “skims the body”,

    “frames the silhouette”,

    “softens every line”,

]

`
These verbs are used in editorial + alt text.




     3. Add more confidence phrases



`python

CONFIDENCE_PHRASES = [

    # existing ones…

    “made to move with you”,

    “built for everyday luxury”,

    “designed to outlast the moment”,

]

`



These close out descriptions with a brand‑consistent promise.




     4. Add more editorial frames



Frames are templates like:



`python

EDITORIAL_FRAMES = [

    # existing ones…

    “{adj} lines meet {mood} ease for {occasion} moments.”,

    “{adj} structure with a {mood} attitude, built for {occasion}.”,
]

`



They’re used in brand_language.py and filled with:



- adj

- mood (persona / vibe)

- occasion (category / season)




How to test new vocab safely



1. Add a few new items.

2. Run:



`bash

Python -m mvqueen_engine.main

`



    3. Try a few different product texts and read:



- editorial_long

- alt_long

- seo_primary

- tags

- metafields
If the tone feels off, tweak the vocab—not the engine.
