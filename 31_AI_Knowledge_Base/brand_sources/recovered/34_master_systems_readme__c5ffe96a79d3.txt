## System Upgrade Protocol

When any system needs updating:

1. **Identify the change needed** — what is not working or needs improvement?
2. **Check doctrine alignment** — does the change align with brand values?
3. **Document the change** — update the relevant system file
4. **Update dependencies** — what other systems does this affect?
5. **Test before deploying** — never push untested changes to live systems
6. **Log the upgrade** — version control all system changes
7. **Review impact** — measure the effect of the change after 30 days
