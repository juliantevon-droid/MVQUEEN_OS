## How to deploy from Termux (first time)

### Step 1 — Sync this folder from Drive to your phone

```bash
# First confirm your rclone remote name
rclone listremotes

# Then sync (replace 'gdrive' with your actual remote name)
rclone copy gdrive:MVQUEEN_OS/agents/ /storage/emulated/0/MVQUEEN_OS/agents/
```

### Step 2 — Run the installer

```bash
cd /storage/emulated/0/MVQUEEN_OS/agents/
chmod +x install_agent.sh
bash install_agent.sh
```

This single command:
- Confirms rclone is working
- Creates all required directories
- Initializes memory files if missing
- Installs Python dependencies (pyyaml, requests)
- Runs a dry-run to validate everything

### Step 3 — Run the agent manually

```bash
# Dry-run (safe — no Shopify writes)
python /storage/emulated/0/MVQUEEN_OS/agents/agent_runner.py \
  --agent wfgen-ecom-001 \
  --dry-run

# Live run (only after dry-run passes)
python /storage/emulated/0/MVQUEEN_OS/agents/agent_runner.py \
  --agent wfgen-ecom-001
```

## Adding your Shopify credentials

Edit memory/preferences.md and add:

```
## Shopify API
- Shop domain: your-store.myshopify.com
- API version: 2024-01
- Access token: shpat_xxxxxxxxxxxx
```

Do NOT put your access token in the YAML definition file.
Always keep credentials in memory/preferences.md only.
