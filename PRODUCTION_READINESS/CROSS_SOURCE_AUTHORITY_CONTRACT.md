2. Compare content, modified time, purpose, and canonical GitHub counterpart.
3. Classify each item: CANONICAL / REFERENCE / DUPLICATE / SUPERSEDED / ARCHIVE-CANDIDATE / CONFLICT.

5. Never import executable Drive code over current GitHub `main` automatically.
